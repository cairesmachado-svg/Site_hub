# Site Hub · Igor Caires Machado

Site pessoal e hub de pesquisa de Igor Caires Machado.

## Objetivo

Reunir, em uma arquitetura única:

- perfil acadêmico e profissional;
- agenda e programas de pesquisa;
- projetos em andamento e concluídos;
- publicações e produtos;
- ensino e pesquisa científica agentiva;
- links para Lattes, LinkedIn, GitHub e demais identificadores;
- cartão digital institucional.

## Tecnologia

O site é estruturado em Quarto e destinado à publicação pelo GitHub Pages.
